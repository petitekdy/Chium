# 치움 · 사진 한 장으로 방 정리·꾸미기

방 사진을 올리면 AI가 정리 순서와 컨셉별 꾸미기 플랜, 필요한 아이템을 추천해주는 서비스예요.

👉 **서비스 바로가기: https://claude.ai/artifact/Ya7JcqFBjJjUfn7U5t4UNU**

## 주요 기능
- **정리 코치**: 사진 속 문제 구역 표시, 정리 순서 체크리스트, 크기에 맞는 수납템 추천
- **꾸미기 코치**: 방 전체 컨셉 팔레트, 공간별 할 일, 컨셉에 맞는 아이템 추천
- 촬영 가이드와 사진 품질 체크, 진행 상황 저장, 결과 카드 이미지 저장

## 이용 방법
1. 위 링크를 열고 정리 코치 또는 꾸미기 코치를 골라요.
2. 사진을 올리고 원하는 방향, 크기, 예산을 입력해요.
3. "플랜 받기"를 누르면 20~60초 뒤에 결과가 나와요.
